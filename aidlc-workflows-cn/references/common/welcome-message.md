# 👋 欢迎使用 AI-DLC（AI 驱动的开发生命周期）！👋

我将引导您完成一个自适应软件开发工作流，它会智能地根据您的特定需求进行定制。

## 什么是 AI-DLC？

AI-DLC 是一个结构化但灵活的软件开发流程，它适应您项目的需求。可以把它想象成拥有一位经验丰富的软件架构师，他会：

- **分析您的需求**，并在需要时提出澄清问题
- **基于复杂度和风险规划最佳方案**
- **为简单变更跳过不必要的步骤**，同时为复杂项目提供全面覆盖
- **记录所有内容**，让您拥有完整的决策和理由记录
- **引导您完成每个阶段**，带有清晰的检查点和审批门禁

### 阶段分解：

**INCEPTION 阶段** - *规划与应用设计*
- **目的**：确定构建什么（WHAT）和为什么构建（WHY）
- **活动**：理解需求、分析现有代码（如有）、规划方案
- **输出**：清晰的需求、执行计划、关于并行开发工作单元数量的决策
- **您的角色**：回答问题、审查计划、批准方向

**CONSTRUCTION 阶段** - *详细设计、实施与测试*
- **目的**：确定如何构建（HOW）
- **活动**：详细设计（需要时）、代码生成、全面测试
- **输出**：可运行的代码、测试、构建说明
- **您的角色**：审查设计、批准实施计划、验证结果

**OPERATIONS 阶段** - *部署与监控（未来）*
- **目的**：如何部署（DEPLOY）和运行（RUN）它
- **状态**：未来部署和监控工作流的占位符
- **当前状态**：构建和测试活动在 CONSTRUCTION 阶段处理

## 关键原则：

- ⚡ **完全自适应**：每个子阶段根据您的需求独立评估
- 🎯 **高效**：简单变更仅执行必要的子阶段
- 📋 **全面**：复杂变更获得带所有保障的完整处理
- 🔍 **透明**：工作开始前您可以看到并批准执行计划
- 📝 **有记录**：所有决策和变更的完整审计追踪
- 🎛️ **用户控制**：您可以请求包含或排除子阶段

## 接下来会发生什么：

1. **我将分析您的工作区**，以确定这是新项目还是现有项目
2. **我将收集需求**，并在需要时提出澄清问题
3. **我将创建执行计划**，显示我提议运行哪些子阶段以及为什么
4. **您将审查并批准**该计划（或请求变更）
5. **我们将执行该计划**，在每个主要子阶段设置检查点
6. **您将获得可运行的代码**，附带完整的文档和测试

AI-DLC 流程会适应：
- 📋 您的意图清晰度和复杂度
- 🔍 现有代码库状态
- 🎯 变更的范围和影响
- ⚡ 风险和质量要求
