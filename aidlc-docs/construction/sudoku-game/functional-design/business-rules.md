# Business Rules - unit: sudoku-game

## 谜题规则

| ID | 规则 |
|---|---|
| BR-01 | 生成的谜题必须有且仅有一个解（countSolutions(grid, 2) == 1） |
| BR-02 | 预填数范围：简单 40-45、中等 32-39、困难 26-31、专家 22-25 |
| BR-03 | 预填格（givens ≠ 0）不可修改、不可清除、不可标注笔记 |

## 填入与冲突规则

| ID | 规则 |
|---|---|
| BR-04 | 填写模式下，输入 1-9 覆盖当前格用户值（预填格除外） |
| BR-05 | 填入值与同行/同列/同宫其他非空格同值时，所有涉及格标记为冲突高亮；冲突消除后高亮立即移除 |
| BR-06 | 填入值与 solution 不符：数字保留在格内并以错误样式（红色）呈现，mistakes+1 |
| BR-07 | 填入值与 solution 一致：不计错误；自动清除同行/列/宫其他格中该值的候选数笔记 |
| BR-08 | 清除操作（Delete/Backspace/清除键）仅作用于用户填写的格子 |

## 笔记规则

| ID | 规则 |
|---|---|
| BR-09 | 笔记模式下输入 1-9 为标注/取消该候选数（切换语义），不写入正式值 |
| BR-10 | 笔记仅在空格（无正式值）上有效；正式填入后该格笔记清空 |
| BR-11 | 笔记模式不改变错误计数，不触发冲突判定 |

## 胜负规则

| ID | 规则 |
|---|---|
| BR-12 | 81 格全部非空且全部与 solution 一致 → 胜利；计时停止，展示用时，清除存档 |
| BR-13 | mistakes 达到 3 → 失败；棋盘锁定（拒绝一切修改操作），清除存档 |
| BR-14 | 棋盘填满但存在错误值 → 不判定胜利（游戏继续，直至改正或失败） |

## 提示规则

| ID | 规则 |
|---|---|
| BR-15 | 提示填入的值与 solution 一致，不计错误，该格此后视为锁定（等同预填） |
| BR-16 | 无空格可提示时，提示操作无效且不产生异常 |

## 撤销/重做规则

| ID | 规则 |
|---|---|
| BR-17 | 撤销/重做覆盖 fill、erase、note、hint 四类操作 |
| BR-18 | 撤销恢复值、笔记、关联笔记清除、mistakes 的完整快照 |
| BR-19 | 新操作清空重做栈；reset 清空全部历史 |
| BR-20 | 撤销栈/重做栈为空时对应操作无效且不产生异常 |

## 计时与存档规则

| ID | 规则 |
|---|---|
| BR-21 | 计时从谜题呈现开始；页面不可见期间暂停；胜利/失败时停止 |
| BR-22 | 存档包含 difficulty、givens、solution、board、notes、mistakes、elapsedSeconds、history、status 与 version |
| BR-23 | 存档读取失败（解析/版本/结构校验）一律降级为新游戏，不抛出异常阻断启动 |
| BR-24 | 存档清除触发点：胜利、失败、新游戏开局、reset 重开（reset 后 status 仍为 playing，先清除旧存档，重置状态由后续自动存档写入） |
| BR-25 | 某数字的 9 个位置全部填对（board 与 solution 一致）时，NumberPad 对应数字按钮置灰禁用；不再完整（如被清除/撤销）时按钮恢复可用 |
| BR-26 | 填对数字时该格播放正面反馈特效（粒子爆发/光环/闪格）；特效不阻塞输入、不影响游戏逻辑判定 |
| BR-27 | 连击（连续填对，中间无填错）使特效按档位升级：1-2 基础、3-5 加强、6-8 大幅加强、9+ 全屏；档位越高粒子越多、范围越大 |
| BR-28 | 填对后某行/列/宫 9 格全部与 solution 一致时，触发该区域整体扫光特效 |
| BR-29 | 连击 ≥3 出现棋盘边框脉冲；≥6 叠加棋盘上升粒子；≥9 叠加沿屏幕边缘漂浮的粒子框；氛围特效随连击档位换色 |
| BR-30 | 填错时该格播放破碎动画并震屏，连击清零，全部持续氛围特效立即消失；reset/新游戏/离开场景时特效同样重置 |
