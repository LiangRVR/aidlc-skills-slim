# Personas - 数独 Web 游戏

## Persona 1: 新手玩家 · 小林

- **特征**：22 岁，偶尔玩数独放松，对规则熟悉但解题技巧有限
- **设备**：个人电脑，Chrome 浏览器，鼠标操作为主
- **目标**：在低难度下顺利解完一盘，享受过程而非挑战极限
- **动机**：休闲放松、碎片时间娱乐
- **痛点**：
  - 容易填错数字，希望有即时的冲突提醒
  - 卡关时需要提示帮助
  - 需要候选数笔记辅助推理
  - 担心中途离开丢失进度
- **常用功能**：简单难度、候选数笔记、提示功能、冲突提示、存档续玩

## Persona 2: 资深玩家 · 老周

- **特征**：35 岁，数独爱好者，追求解题速度与高难度挑战
- **设备**：个人电脑，键盘操作为主（数字键输入）
- **目标**：在困难难度下快速解题，追求零错误与最佳用时
- **动机**：自我挑战、计时竞速
- **痛点**：
  - 误操作时需要快速撤销，不想因此重开
  - 希望错误次数有限制以增加挑战性
  - 需要随时重开当前谜题或换难度
- **常用功能**：困难难度、键盘输入、计时器、撤销/重做、错误限制、新游戏/重开

## Persona 3: 联机玩家 · 阿杰（第四轮新增）

- **特征**：28 岁，喜欢和朋友/陌生人一起玩游戏的社交型玩家，数独水平中等
- **设备**：个人电脑或家中另一台设备（局域网联机），鼠标操作为主
- **目标**：与另一名玩家共同完成一盘数独，享受协作过程与实时互动
- **动机**：社交娱乐、协作解题的陪伴感
- **痛点**：
  - 不想注册登录，希望打开就能联机
  - 担心对方的操作干扰自己的游戏体验（特效、提示应互不打扰）
  - 掉线或对方退出后不想整局作废
  - 希望一眼区分哪些数字是对方填的
- **常用功能**：线上模式、自动匹配、实时同步、笔记协作、断线补位
- **未来方向备注（非当前版本范围）**：后续版本计划引入对抗性玩法（按各自填对数计分，分高者胜出）；当前版本为纯合作制，该画像先行建立以承接演进
- **【第五轮落地备注】**上述演进已实现为竞速对抗模式（FR-31~FR-40）：本画像的协作向描述（笔记协作、断线补位、共同完成）仅对应历史合作制版本；线上模式现行行为见 US-31~US-40 与 P4

## Persona 4: 求胜型玩家 · 小凯（第五轮新增）

- **特征**：26 岁，对抗类游戏爱好者，数独水平中上，享受实时压过对手的成就感
- **设备**：个人电脑（局域网联机），键盘+鼠标混合操作，手速快
- **目标**：在抢分对局中比分压过对手，赢下每一局
- **动机**：竞争快感、即时分数反馈、连击滚雪球
- **痛点**：
  - 讨厌自己辛苦标注的笔记被对手白嫖
  - 担心对手恶意填错占位、恶心人
  - 担心对手打不赢就断线跑路，对局不了了之
  - 讨厌规则漏洞（刷分、穷举猜数）破坏公平
- **常用功能**：实时比分、连击加分、错填格反抢覆盖、笔记私有、终局结算
