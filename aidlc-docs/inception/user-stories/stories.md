# User Stories - 数独 Web 游戏

**拆分方式**：Feature-Based（与 requirements.md 的 FR 一一映射）
**画像**：P1 = 新手玩家·小林，P2 = 资深玩家·老周，P3 = 联机玩家·阿杰（第四轮新增）
**验收标准格式**：Given/When/Then

---

## US-01 谜题生成（FR-1）｜画像：P1, P2

**As a** 玩家
**I want** 系统为我随机生成一盘数独谜题
**So that** 每局都有新的挑战且保证可以解出

### 验收标准
- **Given** 玩家开始新游戏，**When** 谜题生成完成，**Then** 棋盘呈现部分预填数字，且该谜题存在唯一解
- **Given** 任意两次新游戏，**When** 分别生成谜题，**Then** 两次谜题布局不完全相同（随机性）
- **Given** 玩家点击新游戏，**When** 谜题正在生成，**Then** 生成过程在 1 秒内完成，不出现界面卡死

## US-02 难度选择（FR-2）｜画像：P1, P2

**As a** 玩家
**I want** 在开始新游戏时选择难度（简单/中等/困难）
**So that** 我可以匹配自己水平的挑战

### 验收标准
- **Given** 玩家发起新游戏，**When** 界面展示难度选项，**Then** 提供"简单/中等/困难"三个中文选项

> 第三轮扩展（FR-14 / US-14）：难度选项增加"专家"，共四档。
- **Given** 玩家选择"简单"，**When** 谜题生成，**Then** 预填数字数量多于"困难"难度（挖空更少）
- **Given** 玩家选择某难度，**When** 谜题生成完成，**Then** 当前难度在游戏界面可见

## US-03 数字填写（FR-3）｜画像：P1, P2

**As a** 玩家
**I want** 点击格子后用屏幕数字键盘或物理键盘填入数字
**So that** 我可以按自己习惯的方式解题

### 验收标准
- **Given** 玩家点击一个空白可填格，**When** 点击屏幕数字键 N（1-9），**Then** 该格显示数字 N
- **Given** 玩家选中一个可填格，**When** 按下物理键盘数字键 N，**Then** 该格显示数字 N
- **Given** 玩家点击题目预填格（给定数字），**When** 尝试输入任何数字，**Then** 该格内容不变，且预填格与用户填写数字在视觉上有明确区分
- **Given** 玩家选中已填数字的可填格，**When** 按下删除键（Delete/Backspace）或清除按钮，**Then** 该格数字被清除

## US-04 冲突提示（FR-4）｜画像：P1, P2

**As a** 玩家
**I want** 填入与行、列或宫重复的数字时立即看到提示
**So that** 我能及时发现并修正错误

### 验收标准
- **Given** 棋盘中某行已有数字 5，**When** 玩家在该行另一格填入 5，**Then** 冲突的格子立即以高亮（如红色）标识
- **Given** 存在冲突高亮，**When** 玩家修正使冲突消除，**Then** 高亮立即消失
- **Given** 同列或同宫存在重复，**When** 玩家填入冲突数字，**Then** 同样触发高亮提示

## US-05 完成判定（FR-5）｜画像：P1, P2

**As a** 玩家
**I want** 正确填满棋盘后得到胜利反馈
**So that** 我有完成游戏的成就感

### 验收标准
- **Given** 棋盘 81 格全部填满且数字全部正确，**When** 最后一格填入完成，**Then** 系统判定胜利并展示胜利反馈（含本局用时）
- **Given** 棋盘已填满但存在错误数字，**When** 玩家填满最后一格，**Then** 不触发胜利判定

## US-06 候选数笔记（FR-6）｜画像：P1

**As a** 新手玩家
**I want** 在格子里标注多个候选数笔记
**So that** 我可以记录推理过程辅助解题

### 验收标准
- **Given** 玩家开启笔记模式，**When** 在选中格点击数字 1-9，**Then** 该格以小字号标注/取消标注对应候选数，而非正式填入
- **Given** 玩家处于笔记模式，**When** 切换回填写模式并正式填入数字，**Then** 该格显示正式数字且候选数标注被清除
- **Given** 某格正式填入数字 N，**When** 填入完成，**Then** 同行、同列、同宫其他格中标注的候选数 N 被自动清除

## US-07 计时器（FR-7）｜画像：P2

**As a** 资深玩家
**I want** 游戏自动计时
**So that** 我可以挑战自己的解题速度

### 验收标准
- **Given** 新谜题生成完毕，**When** 游戏开始，**Then** 计时器从 0 开始自动计时并在界面可见
- **Given** 游戏进行中，**When** 玩家达成胜利，**Then** 计时停止并在胜利反馈中展示总用时
- **Given** 游戏进行中（未结束），**When** 玩家查看界面，**Then** 计时器持续更新（mm:ss 格式）

## US-08 提示功能（FR-8）｜画像：P1

**As a** 新手玩家
**I want** 卡关时请求系统帮我填入一个正确数字
**So that** 我可以继续推进而不至于放弃

### 验收标准
- **Given** 棋盘存在未填空格，**When** 玩家点击"提示"按钮，**Then** 系统自动为一个空格填入正确数字
- **Given** 提示填入的数字，**When** 填入完成，**Then** 该数字视为正确填入（不增加错误次数，且该格不可再修改）
- **Given** 棋盘已无空格（仅剩错误格或无空格可操作），**When** 玩家点击"提示"，**Then** 系统不执行填入且不导致异常

## US-09 错误次数限制（FR-9）｜画像：P2

**As a** 资深玩家
**I want** 错误次数有限制（3 次上限）
**So that** 游戏更有挑战性和紧张感

### 验收标准
- **Given** 玩家填入与正确答案不符的数字，**When** 填入完成，**Then** 错误次数加一并显示当前错误计数（如"错误 1/3"）
- **Given** 当前错误次数已达 2 次，**When** 玩家第 3 次填错，**Then** 系统判定本局失败，展示失败反馈，棋盘不可继续填写
- **Given** 玩家填入正确数字，**When** 填入完成，**Then** 错误次数不增加

## US-10 撤销 / 重做（FR-10）｜画像：P2

**As a** 资深玩家
**I want** 撤销误操作并可以重做
**So that** 我不必因一次手误重开整局

### 验收标准
- **Given** 玩家刚执行了填数/删数/笔记操作，**When** 点击"撤销"，**Then** 棋盘恢复到该操作之前的状态
- **Given** 玩家刚执行了撤销，**When** 点击"重做"，**Then** 被撤销的操作重新应用
- **Given** 操作历史为空（无可撤销）或撤销栈为空（无可重做），**When** 点击对应按钮，**Then** 棋盘状态不变，不出现异常
- **Given** 玩家撤销后执行了新操作，**When** 新操作完成，**Then** 原重做栈被清空

## US-11 本地存档续玩（FR-11）｜画像：P1

**As a** 新手玩家
**I want** 游戏进度自动保存，下次打开可以继续
**So that** 我不用担心中途离开丢失进度

### 验收标准
- **Given** 游戏进行中，**When** 玩家执行填数/笔记等操作，**Then** 当前进度（棋盘状态、难度、用时、错误次数、操作历史）自动保存到 localStorage
- **Given** 浏览器存在未完成的存档，**When** 玩家重新打开页面，**Then** 系统提示"继续上次游戏"或"开始新游戏"两个选项
- **Given** 玩家选择"继续上次游戏"，**When** 存档加载，**Then** 棋盘、难度、用时、错误次数恢复到离开时的状态
- **Given** localStorage 中的存档数据损坏或读取失败，**When** 页面加载，**Then** 系统优雅降级为开始新游戏，不报错卡死

## US-12 新游戏 / 重开（FR-12）｜画像：P2

**As a** 资深玩家
**I want** 随时开始新游戏或重置当前谜题
**So that** 我可以快速切换挑战

### 验收标准
- **Given** 任意游戏状态（进行中/胜利/失败），**When** 玩家点击"新游戏"，**Then** 出现难度选择，确认后生成新谜题并重置计时与错误计数
- **Given** 游戏进行中，**When** 玩家点击"重开"，**Then** 当前谜题恢复为初始状态（清除所有填写与笔记），计时与错误计数重置
- **Given** 存在未完成存档，**When** 玩家选择开始新游戏，**Then** 旧存档被新游戏进度覆盖

## US-13 连击特效（FR-13，第二轮新增）｜画像：P1, P2

**As a** 玩家
**I want** 填对时获得特效反馈且连击越来越华丽，填错时特效破碎清零
**So that** 解题过程充满正面刺激与成就感

### 验收标准
- **Given** 游戏进行中，**When** 玩家填对一个数字，**Then** 该格子播放粒子爆发特效，且不阻塞后续输入
- **Given** 玩家已连续填对多格，**When** 再次填对，**Then** 特效比上一次更华丽（分档升级：单格 → 更大爆发 → 全屏扩散）
- **Given** 玩家填对后使某行/列/宫 9 格全部正确，**When** 填入完成，**Then** 该行/列/宫触发整体区域特效
- **Given** 连击达到高档位，**When** 游戏继续，**Then** 棋盘出现持续氛围特效（边框脉冲/上升粒子）
- **Given** 任意连击状态，**When** 玩家填错一格，**Then** 该格播放破碎动画，连击清零，全部持续特效消失
- **Given** 特效播放中，**When** 玩家继续填数/撤销/笔记，**Then** 操作正常响应，游戏逻辑判定不受特效影响

## US-14 专家难度（FR-14，第三轮新增）｜画像：P2

**As a** 熟练玩家
**I want** 选择比困难更难的"专家"难度
**So that** 获得更高挑战

### 验收标准
- **Given** 主菜单，**When** 玩家点击"新游戏"，**Then** 难度选项包含"专家"且排在"困难"之后
- **Given** 选择专家难度，**When** 新游戏生成，**Then** 谜题预填数在 22-25 之间（少于困难）且有唯一解
- **Given** 专家难度游戏进行中，**When** 查看顶部难度标签，**Then** 显示"专家"

## US-15 游戏模式选择（FR-15，第四轮新增）｜画像：P1, P2, P3

**As a** 玩家
**I want** 开始游戏前先选择"线上游戏"或"本地游戏"
**So that** 我可以决定独自玩还是与他人联机

### 验收标准
- **Given** 玩家进入游戏，**When** 主菜单展示，**Then** 提供"线上游戏"与"本地游戏"两个明确选项
- **Given** 玩家点击任一模式，**When** 页面滑动切换，**Then** 第二屏展示四档难度选择与"返回"按钮（实施期修订新增）
- **Given** 玩家选择"本地游戏"，**When** 进入游戏流程，**Then** 后续行为与既有单机版完全一致（难度选择、存档续玩、全部功能可用）
- **Given** 玩家选择"线上游戏"，**When** 进入游戏流程，**Then** 进入联机匹配流程（见 US-17）

## US-16 免登录联机接入（FR-16，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 不注册不登录就能连接后端开始联机
**So that** 我可以零门槛立即开玩

### 验收标准
- **Given** 玩家选择"线上游戏"，**When** 客户端连接后端，**Then** 全程不出现任何注册/登录/输入账号的界面
- **Given** 后端服务未启动或无法连接，**When** 玩家选择"线上游戏"，**Then** 界面给出明确的中文连接失败提示，不卡死不报错崩溃

## US-17 线上开局与自动匹配（FR-17，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 选好难度后系统自动为我匹配对局
**So that** 我不用手动找房间就能和别人一起玩

### 验收标准
- **Given** 玩家选择线上游戏，**When** 进入匹配前，**Then** 先展示四档难度选择（同 US-02/US-14）
- **Given** 系统中没有可加入的已开始对局，**When** 玩家选定难度，**Then** 自动创建新对局并直接进入游戏，体验与本地游戏一致（单人先玩）
- **Given** 系统中有一局相同难度的可加入对局（进行中且仅 1 名玩家），**When** 玩家选定该难度，**Then** 自动加入该对局并从当前棋盘状态继续
- **Given** 系统中有多局相同难度的可加入对局，**When** 玩家选定该难度，**Then** 加入其中最早开始的一局
- **Given** 系统中没有相同难度的可加入对局、但存在其他难度的可加入对局，**When** 玩家选定难度，**Then** 按档位距离升序（同距离更难档优先）加入最早开始的对局（设计评审细化：选"中等"顺序为 困难 → 简单 → 专家；选"困难"为 专家 → 中等 → 简单）
- **Given** 对局已有 2 名玩家，**When** 新玩家请求匹配，**Then** 该对局不出现在可加入列表中

## US-18 双人实时状态共享（FR-18，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 实时看到对方在同一棋盘上的填数、错填和笔记
**So that** 我们像坐在同一张桌子前玩同一盘数独

### 验收标准
- **Given** 双人对局进行中，**When** 一方填入数字（对或错），**Then** 对方界面在局域网延迟内（<200ms）同步显示该格变化
- **Given** 双人对局进行中，**When** 一方修改某格笔记，**Then** 对方界面同步显示该格笔记变化
- **Given** 双方几乎同时操作同一格，**When** 服务端处理完成，**Then** 两端最终显示一致的棋盘状态（服务端状态为权威）
- **Given** 一方刚加入进行中的对局，**When** 初始同步完成，**Then** 其棋盘与服务端当前状态完全一致（含对方已填数字与笔记）

## US-19 新玩家加入提示（FR-19，第四轮新增）｜画像：P3

**As a** 已在局玩家
**I want** 新玩家加入时在界面右上方看到非阻塞提示
**So that** 我知道有人加入了，但我的操作不被打断

### 验收标准
- **Given** 玩家单人线上对局进行中，**When** 新玩家匹配加入，**Then** 已在局玩家界面右上方出现提示（如"有玩家加入"）
- **Given** 加入提示显示时，**When** 已在局玩家正在输入/笔记/撤销，**Then** 操作不被打断、不弹模态框
- **Given** 新玩家加入，**When** 任意时刻，**Then** 已在局玩家无任何阻止对方加入的操作入口

## US-20 特效与视觉隔离（FR-20，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 只有自己填对才看到连击特效，对方填的数字用颜色区分
**So that** 我的游戏反馈不受对方干扰，又能看清是谁填的

### 验收标准
- **Given** 双人对局进行中，**When** 自己填对一格，**Then** 本端正常触发连击特效（US-13 全规则适用）
- **Given** 双人对局进行中，**When** 对方填对一格，**Then** 本端仅显示该格被填入数字，不触发任何特效，且不影响本端连击计数
- **Given** 对方填入的正确数字，**When** 在本端棋盘上显示，**Then** 用黑色区分（自己填的为蓝色；实施期修订，原"对方蓝/自己黑"作废）
- **Given** 任一方填错，**When** 两端棋盘显示，**Then** 两端均将该格标红
- **Given** 对方填错，**When** 本端显示该错填格，**Then** 本端不播放破碎特效、不清零本端连击

## US-21 笔记共享与联动清除（FR-21，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 与对方互相看到、互相修改笔记，填对后双方笔记同步清理
**So that** 我们可以协作推理、共享候选数信息

### 验收标准
- **Given** 双人对局进行中，**When** 一方在某格标注/取消候选数，**Then** 对方界面同步该格笔记变化
- **Given** 某格已有对方标注的笔记，**When** 自己修改该格笔记，**Then** 修改生效并同步给对方（笔记不区分归属）
- **Given** 任一方填对数字 N，**When** 填入完成，**Then** 双方界面上同行/列/宫各格笔记中的 N 均被清除

## US-22 合作制共同胜利（FR-22，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 棋盘完成时双方共同获胜
**So that** 我们共享协作完成的成就感

### 验收标准
- **Given** 双人对局中棋盘 81 格填满且全部正确（无论各自由谁填入），**When** 最后一格填入完成，**Then** 双方均看到胜利反馈与共享用时
- **Given** 一方已判负旁观（US-23），**When** 另一方填满棋盘且全部正确，**Then** 双方均看到胜利反馈

## US-23 独立错误计数与旁观（FR-23，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 错误次数各自独立计算，错满 3 次只判我负而不连累对方
**So that** 我的失误不毁掉对方的对局

### 验收标准
- **Given** 双人对局进行中，**When** 一方填错，**Then** 仅该玩家的错误计数加一，双方界面各自显示自己的错误计数
- **Given** 一方错误达 3 次，**When** 第 3 次填错，**Then** 仅该玩家判负转为旁观（可看棋盘，不可输入/笔记/撤销），另一方继续游戏不受影响
- **Given** 一方已旁观，**When** 另一方继续操作，**Then** 旁观者界面实时同步棋盘变化

## US-24 共享计时（FR-24，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 双方看到同一个从对局创建起算的时钟
**So that** 我们对"这局玩了多久"有一致认知

### 验收标准
- **Given** 线上对局创建，**When** 对局开始，**Then** 计时从房间创建时刻起算并在界面可见
- **Given** 第二名玩家中途加入，**When** 其界面加载完成，**Then** 其时钟与服务端时钟一致（非从 0 起算）
- **Given** 一方页面切到后台，**When** 返回对局，**Then** 时钟仍与服务端一致（不因本地暂停而变慢）

## US-25 线上撤销/重做与提示限制（FR-25，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 撤销只回退我自己的操作、线上没有提示按钮
**So that** 我的撤销不抹掉对方的成果，对局也保持公平

### 验收标准
- **Given** 双人对局中自己执行过填数/笔记操作，**When** 点击"撤销"，**Then** 仅回退自己的最近一次操作，对方已填内容不受影响
- **Given** 对方刚执行了操作，**When** 自己点击"撤销"，**Then** 不回退对方的操作
- **Given** 线上对局进行中，**When** 查看控制区，**Then** "提示"按钮禁用或不可见

## US-26 错填擦除权限（FR-26，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 能擦除任何错填的红字格（包括对方填错的）
**So that** 我们可以协作清理错误，不必等对方自己动手

### 验收标准
- **Given** 棋盘上存在对方错填的红字格，**When** 自己选中该格并擦除，**Then** 擦除生效并同步给对方
- **Given** 棋盘上存在自己错填的红字格，**When** 对方擦除，**Then** 自己界面同步该格被清空

## US-27 线上对局控制限制（FR-27，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 线上局中禁用重开/新游戏，通过返回菜单退出房间
**So that** 对方不会单方面重置我们共同的进度

### 验收标准
- **Given** 线上对局进行中，**When** 查看控制区，**Then** "重开"与"新游戏"按钮禁用或不可见
- **Given** 线上对局进行中，**When** 玩家想玩新局，**Then** 可通过返回主菜单退出当前房间，再重新选择模式

## US-28 断线与补位（FR-28，第四轮新增）｜画像：P3

**As a** 联机玩家
**I want** 对方掉线后房间保留、空位能被新玩家顶替
**So that** 掉线不会让整局作废，我可以继续玩

### 验收标准
- **Given** 双人对局进行中，**When** 一方断线/关闭页面，**Then** 对局状态完整保留，另一方继续游戏不受中断
- **Given** 对局因断线只剩 1 名玩家，**When** 有新玩家匹配，**Then** 该对局重新进入可加入列表，新玩家补位并从当前棋盘状态继续
- **Given** 新玩家补位加入，**When** 加入完成，**Then** 其个人错误计数从 0 起算（不继承离开者的计数）

## US-29 本地模式回归约束（FR-29，第四轮新增）｜画像：P1, P2

**As a** 单机玩家
**I want** 多人版上线后本地模式体验与之前完全一致
**So that** 我的既有游戏习惯不受影响

### 验收标准
- **Given** 玩家选择本地游戏，**When** 进行任意完整对局流程，**Then** 全部行为与 US-01~US-14 验收标准一致（难度、笔记、提示、撤销、存档、特效等）
- **Given** 本地游戏进行中，**When** 任意时刻，**Then** 无任何联机相关 UI 元素干扰（加入提示、对方颜色数字等不出现）

## US-30 在线人数显示（FR-30，第五轮新增）｜画像：P3

**As a** 联机玩家
**I want** 棋盘界面右上角一直能看到当前房间有几人在游戏中
**So that** 我不必等提示也知道对手是否还在

### 验收标准
- **Given** 线上对局单人进行中（等待匹配），**When** 查看棋盘右上角，**Then** 显示"在线 1/2"
- **Given** 线上对局中，**When** 第二名玩家加入，**Then** 右上角即时更新为"在线 2/2"
- **Given** 双人对局中，**When** 对方离开或断线，**Then** 右上角即时更新为"在线 1/2"
- **Given** 一方错满 3 次转旁观，**When** 查看右上角，**Then** 人数不变（旁观者仍在房间中）
- **Given** 本地模式对局，**When** 查看界面，**Then** 不出现人数显示
