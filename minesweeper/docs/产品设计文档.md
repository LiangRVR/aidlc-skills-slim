## 1. 项目概述

开发一款类似 Windows 经典扫雷的桌面小游戏，支持打包为单个 exe 直接游玩。

| 项目 | 说明 |
|---|---|
| 项目名称 | minesweeper |
| 项目位置 | `D:\Documents\PythonProject\aidlc-skills\minesweeper\`（独立 uv 项目，不影响上层仓库） |
| 技术栈 | Python 3.12 + PyQt6 + uv |
| 打包方案 | PyInstaller 单文件 exe（`--onefile --windowed --icon`） |
| 开发流程 | 轻量 AI-DLC 流程（快速需求确认 → 精简设计 → 直接编码 → 构建测试） |

## 2. 功能范围（标准经典版）

### 2.1 核心玩法

| 功能 | 说明 |
|---|---|
| 布雷与首次安全 | 首次点击后才布雷，保证首点必不是雷（及其周围优先留空） |
| 左键翻开 | 翻开格子；翻到雷则游戏失败 |
| 右键标记 | 循环切换：🚩 旗 → ❓ 问号 → 空白 |
| 左右键同按（chord） | 在已翻开的数字格上，若周围旗数等于数字，则快速展开其余未翻开的格子 |
| 自动展开 | 翻开到 0 雷格时 flood fill 展开相连空白区域 |
| 胜负判定 | 所有非雷格翻开（或全部雷被正确插旗）→ 胜利 😎；点到雷 → 揭示所有雷，失败 😵 |

### 2.2 难度等级

| 难度 | 棋盘 | 雷数 |
|---|---|---|
| 初级 | 9 × 9 | 10 |
| 中级 | 16 × 16 | 40 |
| 高级 | 16 × 30 | 99 |
| 自定义 | 用户输入 行/列/雷数（对话框） | 自定义 |

### 2.3 界面元素

- 菜单栏：新游戏 / 难度选择（初级、中级、高级、自定义）
- 状态栏：剩余雷数计数器（旗数抵扣）、秒表计时器（首次点击启动，胜利/失败停止）
- 笑脸按钮：😀 常态 / 😮 按压 / 😵 失败 / 😎 胜利，点击重开当前难度
- 数字颜色沿用经典配色：1 蓝、2 绿、3 红、4 深蓝、5 棕、6 青、7 黑、8 灰
- 窗口大小随难度自适应调整

## 3. 项目结构

```text
minesweeper/
├── pyproject.toml          # uv 管理，依赖：PyQt6；dev 依赖：PyInstaller、pytest
├── minesweeper/
│   ├── __main__.py         # 入口：QApplication 启动
│   ├── game.py             # 核心逻辑：Board 类（布雷、首次安全、flood fill 展开、胜负判定），与 UI 解耦便于测试
│   ├── ui/
│   │   ├── main_window.py  # 主窗口：菜单栏、笑脸按钮、LCD 计时器与剩余雷数
│   │   ├── cell.py         # 格子按钮：左键翻开、右键插旗/问号、左右键 chord 快速展开
│   │   └── board_widget.py # 棋盘网格布局、根据难度动态调整窗口大小
│   └── resources.py        # 数字颜色、emoji 图标（💣🚩😀😎😵）
├── tests/
│   └── test_game.py        # Board 逻辑单元测试（布雷数量、首次安全、展开算法、胜负判定）
├── assets/
│   └── icon.ico            # exe 图标
├── docs/
│   └── 产品设计文档.md      # 本文档
└── build_exe.py / .spec    # PyInstaller 打包配置
```

**架构要点**：核心游戏逻辑（`game.py`）与 UI 完全解耦，Board 类不依赖 PyQt6，可独立单元测试。
